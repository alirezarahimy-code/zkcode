# سیستم مدیریت توزیع غذا با دستگاه ZKTeco

## 📋 توصیف پروژه

سیستم جامع و خودکار برای مدیریت توزیع غذا در محیط شرکتی با استفاده از:
- **دستگاه حضور و غیاب ZKTeco V21** (اثرانگشتی)
- **چاپگر شبکه‌ای** برای چاپ فیش غذا
- **پایگاه داده Access** برای ذخیره‌سازی اطلاعات
- **VBA** برای منطق تجاری

## ✨ ویژگی‌های اصلی

### 🔐 مدیریت حضور و غیاب
- اتصال Real-Time به دستگاه ZKTeco
- دریافت فوری رویدادهای تردد (< 1 ثانیه)
- Fallback Polling هر 5 ثانیه
- پایش لحظه‌ای تردد‌ها

### 🍽️ مدیریت توزیع غذا
- سفارش‌گیری غذا برای روزهای آینده
- بررسی خودکار سفارش هنگام حضور
- چاپ فیش خودکار در کمتر از 5 ثانیه
- علامت‌گذاری تحویل غذا

### 🖨️ چاپ فیش
- طراحی حرفه‌ای فیش (فارسی)
- پشتیبانی از چاپگر شبکه‌ای (Socket)
- پشتیبانی از چاپگر Windows
- تلاش مجدد اتوماتیک
- تاریخ شمسی و ساعت دقیق

### 📊 گزارش‌ها
- گزارش تردد‌های روزانه
- گزارش سفارشات غذا
- گزارش چاپ‌های موفق
- صادرات CSV برای تحلیل
- لاگ‌های سیستمی و خطا

## 🚀 نصب و راه‌اندازی

### الزامات
- **Access 2010+** (یا Office 365)
- **Windows 7+**
- **SDK ZKTeco** (zlibrary.dll, zkemkeeper.dll)
- **شبکهٔ محلی** برای دستگاه ZK و چاپگر

### مراحل نصب

#### 1️⃣ نصب SDK ZKTeco
```
1. SDK ZKTeco V21 را دانلود کنید
2. zlibrary.dll و zkemkeeper.dll را قرار دهید:
   C:\Windows\System32\
3. SDK را در Access تعریف کنید:
   Tools → References → Browse
```

#### 2️⃣ نصب برنامه
```
1. فایل Access را باز کنید
2. F5 یا دکمهٔ اجرا را فشار دهید
3. فرم اصلی باز می‌شود
4. از منوی تنظیمات: مشخصات دستگاه ZK را وارد کنید
5. تست اتصال را بررسی کنید
```

#### 3️⃣ تنظیمات چاپگر
```
1. از منوی تنظیمات: تنظیمات چاپگر را باز کنید
2. IP و پورت چاپگر را وارد کنید (معمولاً 9100)
3. دکمهٔ "تست" را بزنید
4. اگر موفق: تنظیمات را ذخیره کنید
```
